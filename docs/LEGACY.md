# Legacy branches

Earlier work is kept on separate branches of the repository. None of it is part of the current TUM-VI pipeline.

| Branch | Content |
|---|---|
| `legacy/monodepth2` | The original Monodepth2-style visual odometry: depth and pose networks trained on Redwood and NYU Depth V2, plus ROS 2 and C++ tools |
| `legacy/stereo-training` | Earlier stereo-training work |
| `legacy/torch` | Earlier PyTorch-port work |
| `legacy/D3VO` | Early D3VO-related experiments (development snapshot, no documentation) |

Check one out with `git checkout legacy/monodepth2` (or fetch it first with `git fetch origin legacy/monodepth2`).
